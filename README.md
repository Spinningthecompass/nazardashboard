# Traffic Dashboard — True-IQ / Get-IQ

Дашборд Meta Ads + Campaignswell в стиле Windows XP.

## Как открыть
- **`index.html`** — двойной клик, работает прямо с диска, сервер не нужен.
- **`dist/dashboard.html`** — то же самое одним файлом (для артефакта и пересылки).

## Структура
| Папка | Что внутри | Правится |
|---|---|---|
| `index.html` | только разметка окон и иконок, без данных | руками |
| `css/` | `base` — общие стили · `xp-skin` · `desktop` · `taskbar` · `windows` · `views` — экраны · `manuals` — мануалы | руками |
| `js/views.js` | все экраны: Мой Трафик, Performers, CW Report | руками |
| `js/windows/` | окна Поиска и Схемы аккаунтов | руками |
| `js/desktop/` | главное окно, меню «Пуск» | руками |
| `js/lib/markdown.js` | рендер мануалов | руками |
| `js/core/` | иконки, производные константы | руками |
| `js/app.js` | привязка кнопок и окон | руками |
| `data/` | кампании, аккаунты, performers, гео, воронка, мануалы | **только синком** |
| `assets/img/` | обои и иконки | руками |

`data/*.js` — это JSON с одной строкой-обёрткой `const NAME = …;`. Обёртка нужна, чтобы файлы
читались при открытии с диска: браузер не даёт загружать `.json` по `file://`.

## Обновить данные
В Claude: «обнови данные». Синк перепишет только `data/` (мануалы 04 и 05 пересчитываются,
остальные мануалы сохраняются) и соберёт `dist/dashboard.html`. Всё, что правилось руками в
`css/`, `js/`, `index.html`, остаётся.

## Собрать один файл вручную
```
python3 build.py
```
